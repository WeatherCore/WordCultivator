## 案例1：tribute 家族四连杀（tribute / distribute / contribute / attribute）

### tribute /ˈtrɪbjuːt/
拆分：tri + but + e
1. tri：谐音**吹**（吹捧、致敬）
2. but：**但是**
3. e：词尾

脑洞：使劲吹(tri)，但是(but)不是瞎吹，献上贡品/赞美以示敬意 → 致敬、贡品

### distribute /dɪˈstrɪbjuːt/
拆分：dis + tribute
1. dis：**分开，拆开**
2. tribute：递交、给出去

脑洞：把一堆物资拆开分开(dis)，一份一份递交(tribute)出去 → 分发、分配

### contribute /kənˈtrɪbjuːt/
拆分：con + tribute
1. con：**共同、一起**
2. tribute：递交、献上

脑洞：大家一起(con)往上递交(tribute)物资/力量 → 贡献、促成、投稿

### attribute /əˈtrɪbjuːt/ v. /ˈætrɪbjuːt/ n.
拆分：at + tribute
1. at：朝向、对着
2. tribute：献礼、递交

脑洞：朝着某人(at)递交功劳(tribute) → 把…归因于；引申：事物自带递交出来的东西 → 属性

**家族核心画面**：tribute = 递交上去的献礼
- dis‑：分开递交 → 分配
- con‑：一起递交 → 贡献
- at‑：朝…递交功劳 → 归因

## 案例2：sacred / sacrifice 同源捆绑

### sacred /ˈseɪkrɪd/
拆分：sac + red
1. sac：谐音**杀**（古代杀牲祭祀）
2. red：红，祭祀鲜血通红

脑洞：杀(sac)牲祭祀，鲜血通红(red) → 神圣的、宗教庄严的

### sacrifice /ˈsækrɪfaɪs/
拆分：sacri + fice
1. sacri：绑定 **sacred（神圣的）**
2. fice：联想"费死"，耗费掉

脑洞：为了神圣(sacri)的目的，费(fice)掉珍贵的人或物拿去献祭 → 牺牲、献祭

**对比**：victim 被动受害 vs sacrifice 主动牺牲

## 案例3：eradicate 用户自定义切割

用户要求按 **era‑dicate** 切割（非真实词源，真实是 e‑radic‑ate）。

### eradicate /ɪˈrædɪkeɪt/
拆分：era + dicate
1. era：绑定 erase（橡皮、擦掉）
2. dicate：来自 dictate（强力下达、狠狠执行）

脑洞：拿橡皮(era)，强力执行(dicate)，不是只擦表面，而是彻底连根抹干净 → 根除、消灭

**真实词源备注**：e‑radic‑ate（拔根），但记忆用 era‑dicate 完全OK。

**对比**：erase 擦表面字迹 vs eradicate 连根铲除祸害

## 案例4：nevertheless / nonetheless / notwithstanding 三词对比

### nevertheless /ˌnevəðəˈles/
拆分：never + the + less
脑洞：never绝不 + less减弱 → 外界干扰绝不能把事实减弱掉 → 尽管如此

### nonetheless /ˌnʌnðəˈles/
拆分：none + the + less
脑洞：none全部无效 + less减弱 → 就算一堆不利因素，全都无法抵消结果 → 尽管如此

### notwithstanding /ˌnɒtwɪðˈstændɪŋ/
拆分：not + with + standing
脑洞：不去顺着(not‑with)面前挡着(standing)的阻碍 → 尽管；虽然

**独有考点**：notwithstanding 可当介词，后面直接加名词（另外两个只能做副词）。

## 案例5：torment / retort 同根串联

### torment /ˈtɔːment/
拆分：tor + ment
1. tor：谐音"拖"
2. ment：名词后缀

脑洞：一直拖(tor)着你不放，使你持续煎熬 → 折磨、痛苦

### retort /rɪˈtɔːt/
拆分：re + tort
1. re：回、反过来
2. tort：联想 torment 折磨，顶撞怼回去

脑洞：受到刁难折磨(tort)，直接回(re)头怼过去 → 反驳、回嘴

## 案例6：render / surrender 上下义串联

### render /ˈrendə(r)/
拆分：ren + der
1. ren：谐音"扔"
2. der：联想"得"

脑洞：把东西扔(ren)出去，给到(der)别人手上 → 递交、给予；致使

### surrender /səˈrendə(r)/
拆分：sur + render
1. sur：向下、缴出去（sub变体）
2. render：递交、交出

脑洞：把手里东西向下(sur)递交(render)出去 → 交出、投降

**核心逻辑**：render 交出 → sur‑往下交出 → surrender 投降

## 案例7：guilt 谐音+画面

### guilt /ɡɪlt/
拆分：gui + lt
1. gui：拼音**鬼**
2. lt：联想**漏题**

脑洞：心里有鬼(gui)，坏事漏(lt)出来了 → 内疚、罪责

## 案例8：condemn 群体动作

### condemn /kənˈdem/
拆分：con + dem + n
1. con：全部、一齐
2. dem：谐音"怼"
3. n：词尾辅助

脑洞：所有人一齐(con)怼(dem)他 → 谴责、宣判有罪

## 输出风格总结

从以上案例提炼的共性：
1. **谐音优先**：中文拼音/谐音是第一武器（gui→鬼，tor→拖，tri→吹）
2. **已知词绑定**：学过的词立刻拿来当锚点（sac→sacred，dict→dictate）
3. **动作画面**：每个联想都有动词（拖着、递交、怼、擦掉、杀牲）
4. **家族打包**：同根/同前缀词一起记，用统一核心画面
5. **考研落地**：每个词都给搭配、例句、派生词
6. **主动迭代**：结尾永远问"脑洞不行直接说，我换新的"
