> ### 💭 记单词不必死记硬背
> WordCultivator 是一个 ZCode AI Skill，专为英语单词记忆设计。它不跟你讲词根词缀的枯燥理论，而是用中文谐音、具象画面和自定义拆分，把每个单词变成一个脑洞故事——**看完就记住，记住就忘不掉**。

---

## 🔥 三大铁律

|                                                   🚫 禁止纯词根词缀                                                   |                                                🚫 禁止读音近似联想                                                 |                                                    🚫 禁止敷衍后缀                                                     |
| :------------------------------------------------------------------------------------------------------------------: | :----------------------------------------------------------------------------------------------------------------: | :-------------------------------------------------------------------------------------------------------------------: |
| 不能说"dis 是否定前缀，tract 是拉"就完事。每个拆分部分必须有**具象画面**或**谐音联想**，让抽象的词缀变成看得见的动作。 | 不能说"这个词读音像 XX 所以记住"。必须是**谐音+画面+动作**的完整链条，让读音变成故事里的角色，而不是模糊的"像什么"。 | 不能说"-ate 是动词后缀"一笔带过。后缀也要**参与脑洞**，或至少说明它在画面中的角色——每个字母都有戏份，不能当背景板。 |

## 🧠 七步记忆法

```mermaid
flowchart LR
    S1["1️⃣ 单词头<br/>词形 + 音标"] --> S2["2️⃣ 自定义拆分<br/>不拘泥词源，怎么好记怎么切"]
    S2 --> S3["3️⃣ 逐部分邪修联想<br/>谐音/已知词 → 具象画面"]
    S3 --> S4["4️⃣ 脑洞串联<br/>所有画面串成完整故事"]
    S4 --> S5["5️⃣ 词义 + 考研考点<br/>核心义 · 搭配 · 例句"]
    S5 --> S6["6️⃣ 家族串联 · 易混辨析<br/>同根词打包 · 近义词对比"]
    S6 --> S7["7️⃣ 派生词 + 一句话速记<br/>名词化考点 · 10字钩子"]
```

每一步都指向同一个目标：**让单词在脑子里长根**。从拆分到脑洞到考点，不做一步无用功。

## ✨ 功能全景

- 🔪 **自定义切割** — 用户想怎么切就怎么切（如 eradicate 切 era-dicate），不管真实词源，能记住的切割就是好切割
- 🎭 **谐音库** — 常用片段速查（tri→吹、gui→鬼、tor→拖、sac→杀…），可复用素材降低创作成本
- 🔗 **已知词绑定** — 用学过的词当锚点（如学完 sacred 后，sacrifice 的 sac 就绑定 sacred），形成记忆网络
- 🧩 **脑洞串联** — 各部分画面串成完整叙事，不是孤立联想，而是有因果有剧情的微型故事
- 👨‍👩‍👧 **家族串联** — 同根/同前缀词打包（如 tribute 家族：tribute/distribute/contribute/attribute），用统一核心画面区分
- ⚔️ **易混辨析** — 形近词/近义词一句话说清区别（如 victim 被动受害 vs sacrifice 主动牺牲）
- 📋 **质量自检清单** — 8 项检查确保每次输出都有画面、有脑洞、有考点、有速记、有迭代邀请
- 🔄 **主动迭代** — 结尾永远问"脑洞不行直接说，我换新的"，不满意就换，记到满意为止

## 📚 经典案例

### tribute 家族四连杀

| 单词 | 拆分 | 脑洞 | 意思 |
|------|------|------|------|
| **tribute** | tri + but + e | 使劲**吹**(tri)，**但是**(but)不是瞎吹 → 献上贡品致敬 | 致敬、贡品 |
| **distribute** | dis + tribute | **分开**(dis)，一份一份**递交**(tribute)出去 | 分发、分配 |
| **contribute** | con + tribute | 大家**一起**(con)往上递交(tribute)力量 | 贡献、促成 |
| **attribute** | at + tribute | **朝**着某人(at)递交功劳(tribute) | 归因于；属性 |

> 核心画面：tribute = 递交上去的献礼。dis- 分开递交 → 分配；con- 一起递交 → 贡献；at- 朝…递交功劳 → 归因。

### sacrifice 同源捆绑

```
sacred /ˈseɪkrɪd/
拆分：sac + red
sac → 谐音"杀"（杀牲祭祀）  |  red → 红，祭祀鲜血通红
脑洞：杀牲祭祀，鲜血通红 → 神圣的

sacrifice /ˈsækrɪfaɪs/
拆分：sacri + fice
sacri → 绑定 sacred（神圣的）  |  fice → "费死"，耗费掉
脑洞：为了神圣的目的，费掉珍贵的东西拿去献祭 → 牺牲
```

## 🚀 快速开始

### 安装 Skill

将 `wordcultivator` 文件夹放入你的 ZCode skills 目录，或在 ZCode 中直接加载。

### 使用方式

在对话中直接抛出英文单词，或使用以下触发语：

- "记一下 **surrender**"
- "**contribute** 和 **distribute** 这两个怎么记"
- "帮我把 **eradicate** 拆成 era-dicate 来记"
- "来点邪修记忆法，单词是 **guilt**"

Skill 会自动识别触发场景，按七步法输出完整记忆方案。

### 指定切割方式

```
用户："我想把 eradicate 拆成 era-dicate"
```

Skill 会完全基于你的切割方式展开联想，并在末尾附上真实词源作为备注（可选）。
