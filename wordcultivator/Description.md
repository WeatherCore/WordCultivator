# Description

## 中文版

WordCultivator（邪修联想记忆法）是一个英语单词记忆 Skill，用中文谐音+具象画面+自定义拆分把考研/CET-6/雅思词汇变成过目不忘的脑洞故事。其含金量在记忆方法论：七步标准输出法从拆分到脑洞到考点形成完整记忆流水线，自定义切割不拘泥真实词源以贴合个人思维习惯，谐音库与已知词绑定法提供可复用联想素材并以旧带新形成记忆网络，脑洞串联将碎片联想串成有因果的叙事增强回忆线索，家族串联与易混辨析用统一核心画面对比区分形近词近义词。基于 ZCode Skill 范式，一份 SKILL.md + 经典案例库即完整能力，附带 8 项质量自检清单。适合考研/CET-6/雅思备考者及需快速扩充词汇量的英语学习者。

## English

WordCultivator (Cultivation-Style Mnemonics) is a ZCode Skill that turns English vocabulary into unforgettable stories through Chinese homophony, visual imagery, and custom word splitting — no etymology required, no rote memorization. Its methodology runs on a structured seven-step pipeline: word header → custom split → per-part mnemonic → story chain → meaning with exam collocations → family grouping or confusion disambiguation → derived forms with a one-liner hook. Users split words however they like, ignoring real etymology; a built-in homophony library and known-word binding turn each learned word into an anchor for the next, building a self-reinforcing memory network. Family grouping packages cognate words under a single core image, while confusion disambiguation distinguishes lookalikes in one sentence. A single SKILL.md plus a classic-case reference file delivers the full capability, backed by an eight-item quality checklist. Built for Chinese learners preparing for 考研 (Postgraduate Entrance Exam), CET-6, or IELTS, and anyone who wants vocabulary to stick on the first read.
